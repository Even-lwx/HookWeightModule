# HookWeightModule 吊秤称重模块

本工程是基于 STM32G031 和 ADS1232 的吊秤称重模块，包含称重采集、滤波、校准、串口调试和 PCB 设计。

## 目录

- `code/STM32G031C8T6/`：固件、ADS1232 驱动、重量滤波和校准存储。
- `pcb/ADS1232/`：原理图、PCB 和元件库。
- `analysis_output*/`：本地分析输出目录，不属于工程源文件。

## 固件功能

固件提供零点校准、指定重量校准、多点线性校准、五点中值滤波和定点卡尔曼滤波。校准参数写入 Flash 后，重新上电可恢复保存值。

## 使用方法

使用 Keil MDK 打开 `code/STM32G031C8T6/MDK-ARM/` 中的工程。通过调试串口执行 `zero`、`cal`、`point` 和 `save` 等命令，具体格式以串口调试模块说明为准。上板前确认 ADS1232 接线、桥式传感器激励和电源地连接。
